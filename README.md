# 🧪 LabFlow: The Report Management System

**LabFlow** is a web-based laboratory report management system designed to streamline the process of creating, managing, reviewing, and organizing laboratory reports. The platform provides a centralized environment for students, teachers, and administrators to manage laboratory activities and report workflows efficiently.

## 🚀 Features

* 🔐 **Authentication & Authorization** - Secure user authentication with role-based access for different types of users.
* 📄 **Report Management** - Create, submit, view, update, and manage laboratory reports through a centralized platform.
* 🧑‍🎓 **Student Management** - Manage student information, laboratory submissions, and report history.
* 👨‍🏫 **Teacher & Evaluator Management** - Assign evaluators and manage report review and assessment workflows.
* 🏢 **Department Management** - Organize laboratories, students, and reports according to their respective departments.
* 🔍 **Search & Filtering** - Quickly find reports, students, departments, and other records using search and filtering functionality.
* 📊 **Dashboard & Statistics** - Provides an overview of reports, users, departments, and other system activities.
* 📑 **Report Review & Evaluation** - Enables authorized users to review submitted reports and manage evaluation-related information.
* 📁 **Document Management** - Upload and manage supporting documents and report files.
* 📱 **Responsive UI** - Provides a clean and responsive interface for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

* **Frontend:** Next.js, React.js, TypeScript
* **Styling:** Tailwind CSS, shadcn/ui
* **Forms:** React Hook Form
* **Validation:** Zod
* **HTTP Client:** Axios
* **Authentication:** Better Auth / NextAuth
* **Backend:** REST API
* **Database:** PostgreSQL
* **Version Control:** Git & GitHub
* **Development Environment:** Visual Studio Code

## 🔄 Workflow

1. Users securely log into the system.
2. Students create and submit laboratory reports.
3. Reports are organized and managed through the system.
4. Authorized evaluators review submitted reports.
5. Administrators manage users, departments, and system activities.
6. Users can track report status and maintain their laboratory records.

## 🎯 Objective

The objective of **LabFlow** is to digitize and simplify laboratory report management by replacing fragmented manual processes with a centralized, organized, and efficient digital platform.
